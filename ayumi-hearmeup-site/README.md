# ayumi × hearmeup 4.0

A one-page application for the hearmeup 4.0 open call (Shye, Return Asia Tour, Singapore).

Static site: `index.html`, `img/`, `audio/`. No build step.

## Put it on GitHub
1. Go to https://github.com/new, name the repo `ayumi-hearmeup`, leave it empty, click **Create repository**.
2. On the new repo page, click **uploading an existing file**, drag in everything in this folder (index.html, README.md, vercel.json, and the img and audio folders), then **Commit changes**.

## Deploy on Vercel
1. Go to https://vercel.com/new and sign in with GitHub.
2. Pick the `ayumi-hearmeup` repo, click **Import**.
3. Framework preset: **Other**. Leave build settings empty. Click **Deploy**.

Every later change pushed to GitHub redeploys automatically.
